## 1. 核心概念与价值 (Overview & Core Concept)

- **解决的核心痛点**：此前的预设字幕内容与 YouTube 视频无法对应，导致听解练习和跟读完全错位。
- **全新工作流体验**：
  1. **开箱即用**：载入即是您指定的 10月18日泰语原版（`F4-tJNYDpss`）与中文版（`HR-O2XYifbI`），482 句字幕从第 1 秒到 59 分钟全流程毫秒级对齐。
  2. **粘贴即解析**：用户在 Language Reactor 或 Excel 中全选复制导出文本（包含 `Time`、`Subtitle`、`Machine Translation`），直接粘贴到输入框中，系统秒级自动识别时间（如 `1s`、`1:02`、`58:46`）、泰文、罗马音和中文译文，立即生成全新可交互的对齐轨道。
  3. **分句带读与听解闭环**：支持“听一句泰文 $\to$ 停顿消化 $\to$ 听中文翻译 $\to$ 再听一遍泰文强化”的经典四步循环，点哪句跳哪句。

### B. Language Reactor / Excel 一键直接粘贴弹窗 (LR Direct Paste Modal)
- **输入区域**：大面积纯净文本框，用户从 Language Reactor 导出文件或 Excel 复制后直接 `Ctrl+V`。
- **即时预览**：粘贴后瞬间统计识别结果（例如：`✅ 成功识别 482 句法谈对照 · 总时长约 59 分钟`）。
- **字段容错与智能清洗**：
  - 自动识别首行表头（如 `Time\tSubtitle\tMachine Translation`）并跳过。
  - 兼容 `1s`、`7s`、`1:02`、`01:02`、`58:46`、`1:02:15` 等多种时间格式。
  - 自动区分泰文字符串、罗马音字符串和中文翻译行。
  - 过滤吸气声 `[เสียงสูดหายใจ]` 等舞台说明标签，或作为背景提示呈现。
- **一键套用**：点击【应用并同步到放映机】，立刻载入并存入本地缓存（LocalStorage）。

## 3. 关键架构决策与技术权衡 (Key Product Decisions)

- **决策 1：纯文本智能正则切分 vs 严格格式导入**
  - *选择方案*：智能流式分词状态机（Robust Line-by-Line State Machine）。
  - *原因*：用户从不同版本的 Language Reactor、Chrome 插件复制、网页版 HTML 复制或 Excel 单元格复制时，换行符与制表符（`\t`）排版常有微小差异。状态机能自动依据“时间标头行 $\to$ 罗马拼音行 $\to$ 泰文原文+中文译文”进行高容错串联，绝不报错或丢句。
- **决策 2：泰中双视频的时间轴偏移机制（Time Offset $\Delta t$）**
  - *选择方案*：在当前视频状态中维护 `chineseOffsetSeconds`。
  - *原因*：泰语直播通常有片头静止画面或倒计时，而中文翻录版可能剪掉了片头或额外加入了中文片头。通过维持 $t_{\text{chinese}} = t_{\text{thai}} + \Delta t$，中文播放器在每次跳转或播放时精准匹配。用户如果发现中文版慢了 2 秒，只需点击 `[ +1s ]` 两次或输入 `2.0`，全篇 482 句自动重校，无需逐句改时间。
- **决策 3：旧数据彻底精简**
  - *选择方案*：将 `LESSON_1_SUBTITLES` 替换为解析后的《以四念处对治邪见》真实数据集，删除旧的虚构字句，保留数据结构的完整性。
