# 隆波帕默尊者双语共学系统：链接录入优先级重构、安卓无损体验与全端 Offset 零溢出方案（修订版）

针对学员提出的三项核心关切：① 链接录入与辅助资源优先级倒置（链接输入被折叠埋没，全网平台资源未分类折叠）；② 绝不因苹果系统的限制而损害安卓及电脑端原生双播体验；③ 悬浮底栏最右侧 Offset 偏移量控制块在手机、平板及“手机电脑模式”下溢出屏幕界外的问题，制定本系统化方案。

> [!IMPORTANT]
> **用户关切核验与三大关键原则锁定**：
> 1. **纠正“本末倒置”，提升自定义视频链接为一级视觉核心**：
>    - 核心业务是学员输入或更换中泰两路视频链接（YouTube 直播或第三方视频），输入框必须**默认常驻展开、醒目突出、一键粘贴即载入**；
>    - 辅助资源（“解脱园、甘露雨、法藏、千聊、台湾四念处协会、静虑林、一心、Facebook、Youtube、Podcasts、Spotify、Instagram、Soundcloud、粤语” 等 14 个全网平台）必须收纳在**精简的折叠抽屉/面板中**，不喧宾夺主。
> 2. **坚决捍卫安卓（Android）与 PC 原生无损体验，绝不降级**：
>    - 安卓系统及 PC 浏览器原生支持多个 HTML5 / iframe 视频带声音并发播放，**绝不引入任何对安卓设备的全局静音、限制或降级代码**；
>    - 苹果设备（iOS/iPadOS WebKit）由于系统底层限制同一页面不可两路发声，彻底修复 `ReferenceError: isIOS is not defined` 报错；仅对检测为苹果设备的用户提供清晰提示与友好单声切换（如学员所提：中国画面可隐藏或仅出声，或泰语画面+中文声音），其余 70%+ 安卓与桌面学员享受 100% 原生双轨双声。
> 3. **全端双层响应式 Dock，彻底根除 Offset 屏幕右侧溢出**：
>    - 彻底废除导致溢出的外层 `md:flex-nowrap` 与子项无脑 `shrink-0`；
>    - 手机端（< 640px）采用科学的**双层精工磁贴架构**（上层核心播控，下层进度与 Offset 胶囊）；
>    - 平板（768px~900px）与手机“电脑桌面模式”（虚拟 980px 视口）采用自适应弹性盒，确保最右侧的 `[🔒 +0.0s -0.1 +0.1]` 永远锁定在屏幕安全视口内。

## 1. 概述与核心概念

- **核心价值**：还原本放映机的核心工具属性——让佛友与学员随时输入中泰视频链接，在手机、平板、电脑等任意设备上无障碍同步学习，辅助全网法音资源一触即达。
- **目标用户群与设备覆盖**：
  - **安卓手机学员（占比高）**：享受原生双画面、双音轨独立调节或齐播，体验丝毫不打折；
  - **苹果 iPhone/iPad 学员**：系统无报错，界面友好提示，支持泰语画面+中文译音或画面同步；
  - **桌面电脑 / 手机开启电脑模式学员**：宽屏流线排布，Offset 毫秒级锁定与微调均在视口黄金区域。

## 3. 关键产品与技术决策

### 决策 1：安卓 vs 苹果分流策略，捍卫安卓原生体验
- **原则**：绝不搞“一刀切”。
- **实施机制**：
  - 通过 `isAppleMobile = /iPhone|iPad|iPod/.test(navigator.userAgent)` 严格只圈定苹果 iOS 设备；
  - **安卓（Android）与 PC 电脑**：`isAppleMobile === false`，完全保持原有双视频双音频同时独立播放机制，允许音量独立调节或伴弱 Dim，100% 还原尊者泰文原声与中文同传交融的现场感；
  - **苹果（iOS）**：修复此前丢失变量引发的 `ReferenceError: isIOS is not defined`；针对苹果系统的互斥特性，提供温和提示。学员所说的“中文画面可以不用播放出来，只需要出声音”可作为 iOS 专属备选开关（例如在 iOS 下提供「视频画面+中文音频同播」轻量模式），操作简明，不打扰学员。

### 决策 2：输入框置顶突出，14大辅助平台优雅折叠
- **改变**：
  - 原来在抽屉底部用 `<details>` 折叠隐藏的视频链接输入框，升级为**主操作台显要位置**，包含“泰文视频链接”、“中文视频链接”、“标题”和“基准偏移量”，并配备“📋 从剪贴板粘贴”与“▶ 载入并同步”按钮；
  - 将庞大的外部平台（解脱园、甘露雨、法藏、千聊、台湾四念处协会、静虑林、一心、Facebook、YouTube、Podcasts、Spotify、Instagram、Soundcloud、粤语等 14 大平台）整合为一个设计精美的**折叠面板（Collapsible Directory）**，既满足需要查找素材时的全网索引，又保持日常练习时的界面清爽专注。

### 决策 3：底栏 Offset 控制模块的容器几何约束
- **根因消除**：
  - 移除原 `DualVideoSyncAlignPlayer.tsx` 第 1791 行的 `md:flex-nowrap`，改为根据屏幕断点自动切换双层/单层；
  - 移除右侧组外层的 `shrink-0`，并在整体悬浮底栏加上 `max-w-[calc(100vw-24px)]` 与 `box-border` 强约束；
  - Offset 控制模块单独封装为固定宽度的紧凑胶囊（`w-fit shrink-0`），在小屏与电脑模式下拥有独立的第二行右侧锚点，物理上不可能被挤压出屏幕右边界。

## 4. 技术实施架构与分阶段推进

### 阶段一：修复运行时报错并建立纯净设备判定
1. 修正 `DualVideoSyncAlignPlayer.tsx` 中的变量命名：统一维护设备类型判断，彻底解决 `ReferenceError: isIOS is not defined`；
2. 确保设备逻辑只针对 iOS 生效，安卓用户执行完全无损的双视频播放逻辑。

### 阶段二：重构视频链接输入与辅助平台折叠面板
1. **主控台链接录入区**：
   - 将中泰视频链接输入框提取到主视窗正上方或配置区的一级醒目位置；
   - 支持实时输入校验、YouTube ID 提取与快速载入；
2. **全网法音资源折叠库（14大平台）**：
   - 构建 `DhammaResourceDirectory` 折叠组件，涵盖：
     - 解脱园（官网/直播）
     - 甘露雨 (https://www.ganluyu.net/)
     - 法藏网 (Dhammada)
     - 千聊语音专栏
     - 台湾四念处协会
     - 静虑林
     - 一心
     - Facebook 官方页
     - YouTube 官方专区
     - Podcasts 播客录
     - Spotify 音频
     - Instagram 法句
     - Soundcloud 原音
     - 粤语开示专区
   - 默认折叠收起，带有一键直达徽章与复制链接能力。

### 阶段三：彻底重构悬浮底栏（Floating Player Bar）为全响应式架构
1. **双层/单层响应式分流**：
   - `< 640px`：自动切换为 2 行精致磁贴，第一行播控，第二行信息与 Offset；
   - `640px ~ 1023px`：弹性自适应，绝不单行硬挤；
   - `>= 1024px`：极简单行悬浮岛；
2. **移动端电脑模式（Desktop Site Mode on Mobile）适配**：
   - 约束底栏容器宽度 `max-w-[96vw]`，并加上安全边距，实测在 iPhone/Android 开启“请求桌面网站”时 Offset 模块依然完整可见。

### 阶段四：验证与编译测试
1. 运行 `compile_applet` 确保 TypeScript 严格类型与无任何编译错误；
2. 在不同视口宽度（375px、414px、768px、980px 模拟电脑模式、1440px）验证 Offset 绝不溢出；
3. 验证安卓端双播放完全正常，苹果端无任何报错。
