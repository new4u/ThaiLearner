## 用户确认与核心决策

> [!IMPORTANT]
> 针对您在截图右侧及顶部区域标记的操作逻辑，将“搜索开示”与“视频设置”、“课件制作”彻底打通，并为学员与管理员（`mr.bigsmile@gmail.com`）构建清晰的发布与审核流水线。

- **搜索与设置深度联动**：在顶部放映机操作区增加显要的 `[🔍 搜索开示 (dhamma.cn)]` 与 `[🛠️ 制作课件]` 入口；在搜索结果中可直接 `[⚡ 载入双播设置]` 或 `[🛠️ 送入课件制作]`；在 `[⚙️ 视频链接]` 设置抽屉内也可一键触发“从 dhamma.cn 智能搜索获取”。
- **多态随动轨支持**：中文随动轨原生支持 YouTube 播放器及 dhamma.cn 嗅探出的 HTML5 `<video>` (MP4) 与 `<audio>` (MP3)，与泰文主控轨保持毫秒级联动咬合。
- **学员与管理员协同流**：
  - 普通学员制作、测试卡拉OK并校准后，点击 `[📤 提交审核]`，课件存为 `status: 'pending'`；
  - 管理员在后台审核中心查验，可随时试播任一句对齐效果，点击 `[✅ 批准发布]`；
  - 批准后的课件即刻同步至全员 `[📚 预制课件库]`，供所有同修研习共修。
- **两级持久缓存**：MediaWiki 检索结果享受 60 秒内存热缓存 + 7 天本地持久缓存（UI 标注 `⏱7d`、`⏱23h` 有效期倒计时），减少源站负担。

## 2. 界面与功能模块细化

### 模块 1：顶部工具栏与入口打通 (放映机 Header)
- 顶部保留核心按钮群，清晰排布：
  - `[📚 预制课件库]`：查看官方精校与已审核上线的共学课件；
  - `[🔍 搜索开示 (dhamma.cn)]`：一键滑出检索抽屉，搜索最新法谈与嗅探音频/视频直链；
  - `[🛠️ 制作课件]`：打开课件工坊，支持从搜索结果带入或手动创建；
  - `[⚙️ 视频链接]`：配置中泰链接与毫秒微调，内嵌“🔍 从 dhamma.cn 智能检索填入”快捷纽带；
  - `[📋 导入法谈 (SRT/LR)]`：快速向当前放映机替换字幕。

### 模块 2：开示检索与直链嗅探 (`dhammaLookup.ts` + `DhammaExplorerDrawer.tsx`)
- **检索逻辑**：MediaWiki API 检索 `srwhat=text`，抓取标题、摘要，并将 `<span class="searchmatch">` 转换成精美高亮；
- **媒体嗅探**：通过 `action=parse` 解析页面正文中的 `media.dhamma.cn` 直链，自动识别 `.mp4` 视频与 `.mp3` 音频；
- **7 天缓存**：带 TTL 倒计时（如 `⏱6d 23h`），支持手动刷新穿透；
- **操作按钮**：
  - `[▶ 视频] / [🎧 音频]`：无跨域阻碍的弹窗/内嵌试听；
  - `[⚡ 载入双播]`：直接将媒体地址同步到双播设置并关闭抽屉；
  - `[🛠️ 导入制作]`：直接携带媒体链接进入课件制作工坊。

### 模块 3：课件工坊与卡拉OK实时对齐试播 (`CourseStudioModal.tsx`)
- **多源录入区**：
  - 课题名称、主讲尊者、日期与标签；
  - 泰文原版视频（YouTube 或 MP4 直链）；
  - 中文同传轨（YouTube、MP4 或 MP3 直链，支持从搜索结果自动带入）；
  - 字幕文本：支持直接粘贴 Language Reactor 双语文本或标准 SRT。
- **自动分词与音标解析**：
  - 一键调用朱拉隆功音标词典与拼读规则，自动将泰文断句切词、生成 IPA 音标与音调标注。
- **试播与微调**：
  - 内嵌实时试播测试台，点击任一句可演练卡拉OK下划线进度，微调中泰基准时差（±0.1s）。
- **上传提交**：
  - 学员点击 `[📤 保存并提交审核]`，存入共享课件池（状态为 `pending`）；
  - 若为管理员（`mr.bigsmile@gmail.com`），额外提供 `[⚡ 直接批准发布]` 选项。

### 模块 4：Admin 后台审核中心 (`AdminSanctuaryModal.tsx`)
- 新增 **「📋 课件审核发布」** 专区：
  - 列表展示所有 `pending` 课件；
  - 快速试听卡片：直观显示中泰媒体源、句子总数与提交人信息；
  - 操作按钮：`[🎧 快速试听]`、`[✅ 批准上线]`、`[✏️ 修改编辑]`、`[🗑️ 驳回删除]`；
  - 批准后课件状态流转为 `approved`，立刻在前台全员课件库中展示。

## 3. 技术落地细节

1. **多态随动轨**：播放器中的中文视窗兼容 YouTube IFrame API 与 HTML5 `<video>` / `<audio>` 播放，支持播放、暂停、跳转、音量统一调度。
2. **数据持久化与状态同步**：
   - 课件池存储在 `localStorage` 持久化存储器中（并在有后端/Firestore 时无缝对接）；
   - 初始化包含 10月17日 (1,198句) 与 10月18日 (746句) 官方精校作为基石，新审核课件动态追加。
